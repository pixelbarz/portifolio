# Portfólio Pessoal - José

Portfólio moderno, responsivo e interativo feito com **HTML**, **CSS** e **JavaScript puro**.

## Sobre o projeto

Este site apresenta o perfil de José como estudante, criador digital e futuro jornalista, com foco em:

- Comunicação
- Criatividade
- Tecnologia
- Evolução profissional

## Funcionalidades

- Navbar fixa com menu mobile (hambúrguer)
- Tema claro/escuro com persistência em `localStorage`
- Hero com monitor fake animado
- Animações suaves de entrada (`fade-in`)
- Fundo animado com bolas em movimento
- Seção de links sociais com ícones
- Cards de projetos com imagem e efeito hover
- Layout totalmente responsivo

## Estrutura de arquivos

```txt
.
├── index.html
├── styles.css
├── style.css
├── script.js
├── fachada.png
├── links.png
└── projeto.png
```

## Como executar

1. Abra a pasta do projeto.
2. Clique duas vezes em `index.html` ou abra com uma extensão Live Server no VS Code.

## Personalização rápida

- Texto do site: edite `index.html`
- Cores/estilo/animações: edite `styles.css`
- Interatividade (menu, tema, animações): edite `script.js`
- Imagens dos projetos:
  - `fachada.png`
  - `links.png`
  - `projeto.png`
