# PixelBarz

Meu portfólio pessoal como desenvolvedor front-end. Este é um espaço para conhecer um pouco do meu trabalho, das minhas ideias e da forma como penso experiências digitais.

[Visitar o site](https://josebraz.cc)

## O que você encontra aqui

- Uma apresentação sobre mim e o que valorizo ao criar interfaces.
- Projetos autorais e trabalhos para clientes.
- Links para meu LinkedIn, GitHub e outros canais de contato.
- Uma navegação interativa, com visual inspirado em interfaces digitais.

## Projetos em destaque

- **Casa Trigo Zero** — site de apresentação para uma casa acolhedora.
- **Página de Links** — meus links reunidos em um só lugar, com identidade própria.
- **Biocalculadora** — ferramenta para análise da qualidade do bioetanol.
- **StudyOS** — planner de estudos simples e focado.
